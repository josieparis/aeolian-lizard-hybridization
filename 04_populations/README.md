# 04_populations/

* `paper_populations_runs.sh` — the `populations` calls behind every result in the paper, in pipeline order,
  with a comment on what each one produces. Copied from the logs; paths generalised.
* `all_stacks_commands.tsv` — complete inventory: for each of the 107 Stacks log files on the server
  (`denovo_map`, `gstacks`, `tsv2bam`, `ref_map`, `populations`) its path, the version/date header line and the
  exact command. Includes exploratory runs (Stairway Plot SFS sets, temporal Ne, NewHybrids v1–v3, *P. muralis* ref-map)
  that are not part of the paper. Paths are as they were on the server (`/home/dsalvi/LIZARD/raffonei_siculus/analysis`
  = the project root, later moved).
